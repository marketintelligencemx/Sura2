# Skill: Ficha de competidor PPR

## Estructura obligatoria de la ficha (en `analisis/03-micro-competidores.md`)

### [Nombre] · [Arquetipo: seguro / fondo / híbrido]
**Veredicto en una línea:** qué es este jugador en PPR y por qué importa.

1. **Producto(s):** nombre comercial, estructura, portafolios o fondos disponibles, seguro de vida
   incluido (suma, tipo), aportación mínima inicial y periódica, glide path o elección manual.
2. **Economía para el cliente:** comisiones (administración sobre saldo o sobre aportación, entrada,
   salida, rescate anticipado), rendimiento publicado (etiquetar bruto/neto y periodo), castigo por
   cancelación temprana.
3. **Fiscal:** registrado ante SAT como PPR deducible sí/no; cómo operan la constancia de deducibilidad.
4. **Canal y experiencia:** por dónde se vende (agentes propios, promotorías, independientes, digital),
   app y autoservicio, proceso de contratación.
5. **Comisiones y bonos al canal (tabla, la joya):**

| Concepto | Dato/Rango | Base de cálculo | Fuente | Confiab. |
|---|---|---|---|---|
| Comisión año 1 | | aportación / prima / saldo | | A/B/C |
| Comisión subsecuente | | | | |
| Bono de producción | | | | |
| Bono de persistencia | | | | |
| Concursos y convenciones | | | | |
| Clawback por cancelación | | | | |

6. **Fortalezas / Debilidades:** 3 y 3, específicas (no "buena marca").
7. **Fuentes de la ficha:** lista con URL y fecha de consulta.

## Protocolo de comisiones al canal
- Empieza por lo público: kits de reclutamiento de agentes, convocatorias de promotorías, prensa de
  convenciones, bolsas de trabajo (las vacantes de asesor a veces publican esquemas).
- Sigue con primarias: entrevistas (guion corto: comisión año 1, subsecuentes, base, bonos, clawback).
  Anonimizar siempre: "entrevista con agente de X, jul-2026 · C".
- C exige dos fuentes coincidentes; si solo hay una, reportar como "indicio único 🔍".
- Rangos, nunca puntos. Si el rango es amplio, decirlo y explicar por qué.
